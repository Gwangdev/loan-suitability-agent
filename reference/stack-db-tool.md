# 스택별 캡처 절차 — DB 클라이언트 스크린샷

> DBeaver 등 DB 클라이언트 화면을 증빙으로 쓰는 실행형 보고서에서만 로드한다.

## 크롭

DB 클라이언트 그리드 스크린샷은 상단 헤더+데이터 몇 줄 뒤에 빈 그리드가 화면 하단까지
이어지는 경우가 많다. 그대로 붙이면 문항 수가 늘수록 쪽 여백이 들쭉날쭉해진다.

1. 그레이스케일 변환 후 행(y)마다 다크 픽셀 개수를 센다.
2. 좌측 아이콘 사이드바(Grid/Text/Record 탭 등)와 우측 스크롤바는 콘텐츠와 무관하게 다크
   픽셀을 만들어내므로 스캔 x범위에서 제외한다.
3. 콘텐츠가 있는 행 밴드를 구하고, 밴드 사이 가장 큰 간격을 빈 그리드 구간으로 판단한다.
4. 그 앞(헤더+데이터)과 뒤(하단 상태바)만 남기고 수직으로 이어붙인다.
5. 크롭 후 실제 픽셀 비율로 이미지 높이를 계산한다. 쪽 배치에 고정 상수를 쓰지 않는다.

도구마다 사이드바 위치와 상태바 문구가 다르므로, 위 절차를 그대로 실행하기 전에 스크린샷
한 장으로 사이드바·스크롤바의 x범위를 먼저 확인한다.
