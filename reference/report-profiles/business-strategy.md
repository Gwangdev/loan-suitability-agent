# 보고서 프로필: business-strategy

전략, 기획, 시장·산업 분석과 경영 의사결정 보고서에 사용한다.

## 판단 질문

독자는 어떤 선택을 왜 지금 해야 하는지 판단한다. 시장 정보를 많이 모으는 것보다 선택지를
가르는 변수, 경제성, 실행 가능성, 반대 근거를 선명하게 제시한다.

## 기본 구성

1. **Executive Summary** — 결론, 결정 근거, 우선 조치, 결론을 바꿀 조건
2. **의사결정 질문과 범위** — 결정 주체, 시간 범위, 포함·제외 범위
3. **시장·산업 진단** — 규모보다 구조, 변화 요인, 수익 풀, 고객 행동
4. **선택지 비교** — 동일 기준으로 대안별 가치·비용·위험·선행 조건 비교
5. **권고안** — 선택과 포기, 이유, 적용 조건
6. **실행 로드맵** — 책임자, 순서, 의사결정 게이트, 선행지표
7. **위험과 한계** — 반대 근거, 민감도, 추가 확인 사항

`현황 → 문제 → 해결책`을 주제와 무관하게 강제하지 않는다. 결론에 필요한 분석만 남긴다.

## 증거 우선순위

공식 통계와 규제 문서, 기업 공시, 원자료·조사 방법이 공개된 연구, 검증 가능한 산업 자료,
보조 사례 순으로 사용한다. 검색 결과 요약이나 출처가 재인용한 수치는 원출처로 거슬러 올라간다.

## 권고 작성법

권고에는 행동 주체, 조치, 시점, 선행 조건, 성공·철회 기준을 포함한다. `역량 강화`,
`생태계 조성`, `선제적 대응`처럼 실행을 특정하지 않는 표현만으로 끝내지 않는다.

## 권장 시각화

- 시장 구조와 가치 풀
- 대안 비교표 또는 의사결정 트리
- 기준 시나리오와 민감도 범위
- 단계별 실행 로드맵과 의사결정 게이트
