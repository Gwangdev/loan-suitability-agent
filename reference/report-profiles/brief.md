# 보고서 프로필: brief

1~4쪽 의사결정 메모, ICT 동향 브리프, 이슈 요약에 사용한다.

## 판단 질문

독자는 5분 안에 상황, 의미, 필요한 조치를 파악한다. 짧다는 이유로 출처·조건·반대 근거를
생략하지 않고, 배경과 사례의 수를 줄인다.

## 기본 구성

1. **한 문장 결론**
2. **왜 지금 중요한가** — 변화나 촉발 사건과 영향 범위
3. **판단 근거** — 서로 다른 역할을 하는 핵심 근거 3~5개
4. **권고 또는 선택지** — 행동, 주체, 시점, 조건
5. **주의할 조건** — 결론을 바꿀 변수와 자료 한계
6. **출처** — 본문에서 사용한 원출처만

독립 목차와 별도 표지는 만들지 않는다. 문단을 카드 여러 개로 쪼개지 않는다.

## 정보 밀도

- 첫 화면 또는 첫 페이지에 결론과 핵심 수치를 둔다.
- 표·차트는 합쳐서 1~3개만 사용한다.
- 세부 방법, 긴 사례, 전체 데이터 표는 링크나 부록으로 보낸다.
- 핵심 수치가 없으면 숫자 카드를 꾸며내지 않는다.

## 권장 시각화

- 변화 전후 또는 기준선 비교
- 선택지 2~3개의 짧은 비교표
- 시간 순서가 중요한 사건 타임라인
