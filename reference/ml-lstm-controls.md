# ML/LSTM 서비스 전용 리스크 통제

> 서비스가 LSTM 등 ML 모델을 사용할 때 `/design`에서 추가 적용한다.

- **시간순 분할:** 시계열은 학습·검증·테스트를 시간순으로 분리한다. 무작위 분할·미래 정보 누수(look-ahead leakage) 금지.
- **과적합·드리프트 감시:** 학습/검증 성능 격차, 데이터 분포 변화·개념 드리프트 모니터링 지표를 정의한다.
- **검증 성능 실측:** 백테스트/홀드아웃 실측 값만 성과로 사용한다. 성능 날조 금지, `[미검증]` 성능은 성과로 제시 금지.
- **모델 카드:** 학습데이터 기간·범위, 알려진 한계, 실패 모드, 재현 절차를 문서화한다.
- **도메인 검증 루프:**
  - 금융: "백테스트 ≠ 실거래 성과"를 명시하고 설명가능성·적합성원칙을 반영한다.
  - 반도체: 물리 시뮬레이션/실측 검증 루프 없이는 파라미터 추천을 완료로 보지 않는다.
