# PPT 스타일 가이드 예시 — 노르딕 심플

> 사용법: 이 파일을 `reference/ppt-style.md`로 복사(덮어쓰기)하거나, `/handoff ppt reference/examples/ppt-style-nordic-simple.md`로 직접 지정한다.
> 청중·발표시간·분량은 원 브리프에 없던 정보이므로 "미지정"으로 둔다. 필요하면 채운다.

## 역할
전문 프레젠테이션 디자이너로서 슬라이드를 설계한다.

## 청중·목적
- 발표 대상: 미지정
- 발표 시간: 미지정
- 발표 목적: 미지정

## 톤·어조
- 스타일: 노르딕(Nordic), 카테고리: 심플
- 절제되고 차분한 톤. 장식적 과장 없이 여백과 균형으로 완성도를 표현.

## 분량·구성
- 미지정 (지정 없으면 내용 분량에 맞춰 판단)

## 디자인·시각 방향

**컬러 시스템**
| 용도 | 색상 |
|---|---|
| 배경 | `#F0F4F8` |
| 텍스트 | `#2D3748` |
| 강조 | `#718096` |

**폰트**
- Inter

**무드 & 레퍼런스**
- IKEA, 코펜하겐 인테리어 무드

**디자인 특성**
- 파스텔 뮤트 톤
- 모서리 반경 8px(둥근 모서리)
- 자연광 느낌의 밝고 부드러운 명암
- 따뜻한 기능미(과하지 않은 실용적 미니멀)

**텍스처**
- 린넨 텍스처 3% (은은한 질감, 시각적 노이즈 최소화)

**레이아웃 가이드**
- 본문·텍스트 블록은 좌측 정렬
- 우상단에 원형 장식 요소 배치

## 강조할 점 / 피할 점
- 강조: 여백감, 파스텔 톤의 일관성, 절제된 장식
- 피할 것: 채도 높은 컬러, 각진 모서리, 텍스처 과다, 화려한 그래픽 효과

## 워딩 예시
- 미지정

## 기타 요청
- 컬러·폰트·텍스처·레이아웃 값을 슬라이드 전체에 일관되게 적용할 것
