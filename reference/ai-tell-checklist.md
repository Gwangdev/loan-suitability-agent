# AI 문체 흔적 제거 체크리스트

> `/handoff report`·`/handoff publish`가 생성하는 프롬프트에 포함되며, 초안 작성 후 반드시 통과시켜야 하는 기준이다. 보고서는 `reference/report-contract.md` §6의 통합 감사에서 이 목록을 한 번 적용한다. Claude 감사와 Codex 자체 감사를 연달아 실행하지 않는다.
> 목적은 "AI가 쓴 티를 감추는 것"이 아니라 **읽는 사람이 거부감 없이 내용에 집중하게 만드는 것**이다. 사실을 왜곡해 사람처럼 보이게 만들지 않는다.

## 1. 구조적 흔적 (가장 먼저 잡을 것)

| 흔적 | 증상 | 교정 |
|---|---|---|
| 불릿 남발 | 서술로 충분한 내용을 목록으로 쪼갬 | 서술로 설명되는 내용은 단락으로 쓴다. 병렬 항목이 3개 이상이고 순서가 무의미할 때만 목록 |
| 균질한 단락 길이 | 모든 단락이 3~4문장으로 비슷함 | 1문장 단락과 6문장 단락을 섞는다 |
| 절마다 요약 재등장 | 각 절 끝에 "정리하면~" 반복 | 요약은 결론에서 한 번만 |
| 기계적 접속 | 절을 "먼저 / 또한 / 마지막으로"로 연결 | 접속어를 지우고 내용으로 연결. 지워도 뜻이 통하면 그게 정답 |
| 대칭 과잉 | 모든 절의 하위 구조가 똑같음 | 내용 분량에 따라 비대칭을 허용 |
| 헤딩 과다 | 2~3문단마다 소제목 | 위계는 `report-style.md`의 3단계(장·절·본문)를 넘지 않는다 |
| 요약의 목차화 | Executive Summary가 본문 절을 순서대로 한 문장씩 반복 | 독자의 질문에 먼저 답하고 근거·조치·한계를 중요도순으로 쓴다 |
| 제목과 차트의 무주장성 | `시장 현황`, `분석 결과`처럼 주제만 표시 | 제목에서 해당 절이나 차트가 입증하는 결론을 밝힌다 |
| 부연설명 dash | `[짧은 주장] — [때문이다/우연이 아니라]`로 근거를 덧붙임 | 원인을 문장 뒤에 붙이지 말고 처음부터 원인이 포함된 한 문장으로 통합. 요약·부록을 가리키는 라벨식 dash(`결론 — 상세는 3장 참조`)와는 구분한다 |

## 2. 문장 규칙

과용 표현(`~를 통해`, `중요한 것은`, `기대된다`, `종합적으로` 등)의 **검출은 `gate.py` D5가
한다.** 목록을 여기에 두지 않는다. 검출된 항목은 (a) 삭제, (b) 구체 서술로 치환,
(c) 유지 및 사유 기록 중 하나로 처리한다. 자연스러운 1~2회 사용은 남긴다.

- 한 문장에 한 주장. 평균 40~60자, 80자 초과 시 분할.
- 3항 병렬 습관을 경계한다. `정확성, 효율성, 확장성을 확보했다`처럼 항상 세 개를 나열하지 않는다.
- 근거 없는 헤지(`일반적으로`, `대체로`) 금지. 불확실하면 **불확실한 이유를 명시**한다.
- 수식어보다 수치. `성능이 크게 향상되었다` → `응답 시간이 820ms에서 240ms로 감소했다(n=100, 로컬)`.
- 능동태 우선. 행위자가 중요하지 않은 실험 서술은 피동을 허용한다.

## 3. 내용 흔적

- **모든 것을 성공으로 서술** — 실패·폐기한 접근·미해결 문제가 없으면 AI 티가 난다. 실제로 있었던 실패를 쓴다.
- **일반론 삽입** — "AI 기술의 발전으로~" 같은 배경 문장은 삭제한다. 이 프로젝트에만 해당하는 사실로 시작한다.
- **균형 잡힌 척** — 장단점을 기계적으로 대칭 배치하지 않는다. 근거가 한쪽으로 기울면 기운 대로 쓴다.
- **출처 없는 수치** — 증거 없는 값은 쓰지 않는다. `[미검증]` 표기 후 사용자 확인.
- **판단 없는 자료 나열** — 조사 결과를 순서대로 붙이지 않는다. 독자의 결정과 무관한 사실은 뺀다.

사실·해석·권고의 경계, 장식용 시각화 금지는 `reference/report-contract.md` §3·§5가 이미
다룬다. 여기서 다시 쓰지 않는다.

## 5. 최종 낭독 테스트

작성자가 소리 내어 읽었을 때 다음이면 재작성한다.

- 숨이 차는 문장이 있다 → 분할
- 같은 리듬이 반복돼 지루하다 → 문장 길이 변주
- 내가 말하지 않을 단어가 있다 → 교체
- 읽고 나서 남는 사실이 없다 → 내용 부족. 문체 문제가 아니라 증거 부족
