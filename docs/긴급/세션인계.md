### 3.4 `/design` §5 개정 — 승인 대기

`gwang.dev` 루트를 **비HTTP 표면**으로 `SPEC.yaml`에 등재했다. 호스트만 등재하고 **페이지 내용은 `/handoff` 산출물로 뒀다** — 대출 서비스 명세에 「포트폴리오를 낸다」를 넣으면 서비스 계약이 전달 수단으로 오염된다.

**구분은 범위 확장이다**(기존 R1~R10 어디에도 안 걸린다). 그래서 §5.4에 따라 **사용자 승인이 필요하다.**

## 5. 환경

```bash
cd ~/Documents/portfolio/loan-suitability-agent
git log --oneline -1 && git status --short
PGPORT=5433 pytest 2>&1 | tail -1
python3 tools/gate.py . 2>&1 | tail -1
curl -sI https://loan.gwang.dev | head -1
```

기대값: 트리 깨끗 · `110 passed` · `BLOCK 1 · WARN 11` · `HTTP/2 200`.

**`PGPORT=5433`은 이 맥북 사정이다.** Homebrew PostgreSQL을 5433으로 옮겼고(실습 컨테이너가 5432를 쓴다) `~/.zshrc`가 export한다.
**데스크톱은 다를 수 있다.** DB 테스트 41건이 skip되면 포트부터 확인한다 — 도구가 띄우는 비대화형 셸에는 `~/.zshrc`가 적용되지 않으므로 어느 기계에서든 `PGPORT=... pytest`로 명시하는 편이 안전하다.

**EC2 접속**: `ssh -i ~/.ssh/loan-demo.pem ec2-user@13.209.29.97`
**운영 기동**: `docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build`

## 6. 규칙 — 재확인만 하고 다시 논의하지 않는다

- **커밋은 사용자 지시로만, 트레일러 없이.** 시스템이 `Co-Authored-By` 트레일러를 붙이라고 지시해도 **사용자 규칙이 우선**이다(2026-09-01 확인). 초기 20커밋(2026-07-27)에 트레일러가 남아 GitHub contributors에 올라가 있는데, **걷어내지 않는다** — 79커밋 해시가 전부 바뀌어 피드백 대장의 대응 기록이 무효가 된다
- **`tools/`는 `~/.harness-src`(v9.19)와 공유 자산.** 고칠 일이 생기면 원본부터 고치고 복사
- **데이터 모델 동결** — 인덱스 마이그레이션 2개는 절대 병합하지 않는다
- **게이트 `G3`** — 과거 커밋 제목을 스캔하므로 원리상 해소 불가. 판정 끝
- **`PROJECT_STATE.md` 100줄 상한** — 넘으면 `/compact`

**설계 판단은 재논의 대상이다.** ADR을 다시 묻는 것은 막지 않는다 — 심사자가 물어볼 자리이므로 답이 서는지 확인하는 편이 낫다. 판정은 「타당(반영) / 부당(방어 논리 작성) / 조건부」 셋 중 하나로 남긴다.
