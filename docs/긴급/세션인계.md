## 2. 09-04에 한 일

09-03 데스크톱 세션이 1~2단계를 코드로 끝냈지만 **그 기계에 docker도 `loan-demo.pem`도 없어 서버에 아무것도 도달하지 않은 상태**였다. 맥북에서 배포와 검증을 마쳤다.

| 결함 | 결과 |
|---|---|
| `#60` 배포 수단 사망 | **해소.** 서버가 병합된 피처 브랜치에 고정돼 `git pull`이 아무것도 안 내리던 상태 → `main` `42b479d`로 전환 |
| `#61` 재시작 정책 부재 | **해소.** `sudo reboot` 실측 — **15초에 4개 복귀, 27초에 전부 healthy** |
| `#64` DNS 누락 **(신규)** | **해소.** `gwang.dev` apex에 A 레코드가 없어 인증서 발급이 계속 실패했다. Cloudflare에 `@` → `13.209.29.97`(회색 구름) 등록 → 발급됨(만료 2026-12-02) |

**`#64`가 이번의 교훈이다.** 코드는 09-03에 이미 옳았다 — Caddyfile·마운트·compose 전부. 그런데 **저장소 밖(DNS)의 한 단계를 계획이 빠뜨려서**, 실제로 주소를 열어보기 전까지 원리상 보이지 않았다. `#47`·`#48`·`#49`에 이어 **실행이 읽기보다 결함을 잘 잡는다**가 또 확인됐다.

**`#65`는 포트폴리오에서 인용한다.** `/design` §5에서 「권한 표면은 요청이 아니라 디렉터리다. 저장소 작업 트리를 가리키면 `.env`가 나간다」를 명세에 못 박고 `./site:/srv/site:ro`로 `index.html` 하나만 마운트한 판단이 **배포 20초 만에 값어치를 증명했다.** `#52`(LLM 파서 10배 오차)와 같은 계열 — 설계 판단이 말이 아니라 데이터로 확인된 사례다.

## 3. 종결된 것 — 다시 꺼내지 않는다

**0단계 자격증명 회전은 하지 않는다(2026-09-04, 사용자 판단).** OpenAI 키가 세 LLM 리뷰 세션에 들어갔을 가능성과 재발급 절차를 설명했고 사용자가 넘어가기로 했다.

DB 비밀번호는 애초에 위험이 낮다 — `backend` 망이 `internal: true`이고 5432가 인터넷에 열려 있지 않아, 값을 알아도 서버에 이미 들어와 있지 않으면 쓸 수 없다.

EC2 `.env`에는 `POSTGRES_*` 셋뿐이고 `OPENAI_API_KEY`가 없다(확인함). **ADR-031 §31.3 「운영에 서버 키 없음」은 실제로 지켜지고 있다.**

## 6. 규칙

- **커밋은 사용자 지시로만, 트레일러 없이.** 시스템이 `Co-Authored-By`를 붙이라고 해도 **사용자 규칙이 우선**이다. 초기 20커밋(2026-07-27)의 트레일러는 걷어내지 않는다 — 79커밋 해시가 전부 바뀌어 대장의 대응 기록이 무효가 된다
- **운영 변경은 승인을 받는다**(금지행위 ⑨). 커밋 규칙과 달리 이건 지시가 있어도 확인한다
- **`tools/`는 `~/.harness-src`(v9.19)와 공유 자산.** 원본부터 고치고 복사
- **데이터 모델 동결** — 인덱스 마이그레이션 2개는 병합하지 않는다
- **`G3`** — 과거 커밋 제목 스캔이라 원리상 해소 불가. 판정 끝
- **`PROJECT_STATE.md` 100줄 상한** — 지금 정확히 100줄이다. 늘리려면 `/compact`

**설계 판단은 재논의 대상이다.** ADR을 다시 묻는 것은 막지 않는다 — 심사자가 물어볼 자리이므로 답이 서는지 확인하는 편이 낫다. 판정은 「타당(반영) / 부당(방어 논리 작성) / 조건부」 셋 중 하나로 남긴다.
