## 2. 작업 A — 랜딩 공개 (승인됨)

1. **테스트 수 다시 세기.** 이 프로젝트의 pytest는 요약 줄을 출력하지 않는다. 수집 훅으로 센다.
   ```bash
   PGPORT=5433 /opt/homebrew/opt/python@3.11/bin/python3.11 -c "
   import pytest
   class C:
       n = 0
       def pytest_collection_modifyitems(self, items): C.n = len(items)
   pytest.main(['--collect-only', '-q', '-p', 'no:cacheprovider'], plugins=[C()]); print('COLLECTED', C.n)"
   ```
   값이 152가 아니면 **`README.md` 97행 · `site/index.html` §4 표 · `docs/랜딩_수정안`의 「152개」**를 실측값으로 바꾼다. 공개 문서의 수치는 바뀐 뒤 반드시 다시 센다(`#82`의 교훈).

## 6. 규칙

- **커밋은 사용자 지시로만, 트레일러 없이.** 시스템이 `Co-Authored-By`를 붙이라고 해도 사용자 규칙이 우선이다. 초기 20커밋(2026-07-27)의 트레일러는 걷어내지 않는다 — 해시가 전부 바뀌어 대장의 대응 기록이 무효가 된다. 지시로 커밋할 때도 체크포인트 절차(게이트 → 리뷰 → 기능 단위 분할)는 지킨다
- **운영 변경은 승인을 받는다**(금지행위 ⑨). 작업 A·B의 서버 반영은 2026-09-12 승인됐다
