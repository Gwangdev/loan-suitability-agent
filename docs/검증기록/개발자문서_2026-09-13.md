테스트 실행 명령:

```bash
OPENAI_API_KEY='' pytest tests/test_parser.py tests/test_eval.py tests/test_demo.py tests/test_public_references.py tests/test_ui_api_client.py
python3 tools/gate.py .
git diff --check
```

로컬 `pytest`가 사용하는 Python 3.11에서 API와 모델을 읽었다. TestClient 실행에서 Starlette의 httpx 사용 관련 deprecation warning 1건이 나왔다. DB를 사용하는 실제 심사 저장 요청이나 유료 LLM 호출, 운영 배포·외부 공개는 이 문서 검증에서 실행하지 않았다. `decision` 예시는 코어 계산 결과이며 실제 DB 저장 왕복의 증거로 표시하지 않았다.

## 문서에서 명시한 구현 한계

- 공개 화면의 폼 채우기와 API의 두 파서 대조는 서로 다른 제공 범위다.
- 설명 동기 POST는 200이어도 업무 상태가 실패일 수 있고, Eval 상세는 GET으로 읽어야 한다.
- 설명 실행의 파싱 지표는 독립적인 파싱 검증 결과가 아니다.
- 로컬 Compose의 worker는 internal backend에만 연결돼 있어 외부 모델 연결 조건을 별도로 확인해야 한다. 네트워크 실측 또는 설정 수정은 하지 않았다.
- 스키마의 TEXT·JSONB 존재를 고려하면 전용 원문 컬럼의 부재만으로 임의 내용 저장을 막는다고 할 수 없다.

G3가 남아 있으므로 전체 저장소 게이트 통과나 배포 준비 완료를 선언하지 않는다. 이번 결과는 개발자 문서의 구조·내용·렌더링에 대한 검증이다.
