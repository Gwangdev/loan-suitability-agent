# /debug — 진단

## 로드
`CLAUDE.md` 불변 카드 준수 + `PROJECT_STATE.md` read + **`reference/debug-protocol.md` 로드 후 그 절차를 따른다.**

`PROJECT_LOG.md`는 **같은 증상의 이력이 있는지 확인할 때만** 읽는다. 전문을 읽지 않는다 — 배제된 원인 절만 본다.

## 이 커맨드가 하는 일과 하지 않는 일

**한다:** 재현을 고정하고, 가설마다 반증 관측을 정하고, 원인을 규명한다. 회귀 테스트를 먼저 쓰고 고친다.

**하지 않는다:** 설계를 바꾸지 않는다. 고치려면 설계를 바꿔야 한다는 결론이 나오면 **`/design`으로 되돌아간다.** 여기서 설계를 바꾸면 명세와 코드가 갈라지고 게이트 대조가 무의미해진다.

**절차를 이 파일에 다시 쓰지 않는다.** `reference/debug-protocol.md`가 원본이다. 사본을 만들면 둘이 갈라진다.

## 종료

`debug-protocol.md` §종료 조건 5개를 전부 확인한다. 하나라도 미달이면 완료로 보고하지 않는다.

**보고에 남길 것:** 원인 한 문장 · 배제된 원인 · 회귀 테스트 경로 · 남은 `[미검증]` 라벨 유무.
