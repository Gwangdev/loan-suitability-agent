# /compact — 상태 압축 (LSTM 게이트)

## 실행 시점 (필수)
- `PROJECT_STATE.md`가 **100줄을 초과**했을 때 — 다음 단계로 넘어가기 전에 실행한다
- **개발 착수 직전**, **`/verify` 직전** — 줄수와 무관하게 실행한다
- 세션을 나눌 때 — 다음 세션이 읽을 파일을 먼저 줄인다

**이 커맨드는 기한 압박 시 생략 대상이 아니다.** 압축을 생략하면 이후 모든 단계가 큰 파일을 반복해서 읽는다. 비용은 남은 단계 수에 비례해 늘어난다.

## 로드
`PROJECT_STATE.md` read. (`PROJECT_LOG.md`는 append 대상이므로 전문을 읽지 않는다.)

## 게이트 규칙
- **셀 상태(보존):** 규제·금지행위·데이터 등급·승인 상태·현재 유효한 설계 결정·미해결 라벨·미조치 피드백·중단 사유 — 임의 삭제 금지. 승인 기록은 감사 흔적이다.
- **망각 게이트(제거):** 폐기된 초안, 재생성 가능한 중간 출력, 중복 설명. 되살릴 필요가 없으면 어디에도 남기지 않는다.
- **이동 게이트(`PROJECT_LOG.md`로 내림):** 요구사항 변경 이력, 구현 상세, 테스트 증거 원문, 뒤집힌 설계 결정, 폐기한 접근, 조치 완료된 피드백. **삭제가 아니라 이동이다.**
- **입력 게이트(반영):** 새 정보 중 **승인·검증된 것만** 상태에 반영. `[미검증]`은 미해결 라벨 절에 분리 유지.

## 보존 순서
규제 → 승인 상태 → 현재 유효한 설계 결정 → 미해결 라벨 → 미조치 피드백 → 다음 작업.

## 완료
1. 압축된 상태로 `PROJECT_STATE.md`를 덮어쓴다(버전+1).
2. 내린 내용을 `PROJECT_LOG.md`의 해당 절에 **append**한다. 덮어쓰지 않는다.
3. **셀 상태 항목이 하나라도 사라졌는지 점검**한다. 사라졌으면 압축을 취소하고 이전 버전에서 복구한다.
4. `wc -l PROJECT_STATE.md`로 100줄 이하를 확인한다. 초과면 이동 게이트를 한 번 더 적용한다.
